## B) i18n MODULE DESIGN

### New files (3)

```
src/ui/i18n.js          — engine, ~60 lines
src/ui/strings.en.js    — export const EN = { …flat dotted keys… }
src/ui/strings.de.js    — export const DE = { … }
```

Flat dotted keys, not nested objects: lookup is one property access, no path walker, no deep-merge, and a missing key is a `undefined` not a `TypeError`. Tables are plain objects; values are `string`, `{one, other}` (plurals), or `string[]` (random pick).

### `src/ui/i18n.js` — complete implementation

```js
import { EN } from './strings.en.js';
import { DE } from './strings.de.js';

const TABLES = { en: EN, de: DE };
export const LANGS = ['en', 'de'];
const STORE = 'ud.lang';

let lang = 'en', table = EN;
let pr  = new Intl.PluralRules('en');
let nf0 = new Intl.NumberFormat('en');
let nf1 = new Intl.NumberFormat('en', { minimumFractionDigits: 1, maximumFractionDigits: 1 });

export function initLang() {
  const q = new URLSearchParams(location.search).get('lang');
  let saved = null; try { saved = localStorage.getItem(STORE); } catch {}
  const nav = (navigator.languages?.[0] || navigator.language || 'en').slice(0, 2);
  const pick = LANGS.includes(q) ? q : LANGS.includes(saved) ? saved : LANGS.includes(nav) ? nav : 'en';
  setLang(pick, false);
}

export function getLang() { return lang; }

export function setLang(next, persist = true) {
  lang  = LANGS.includes(next) ? next : 'en';
  table = TABLES[lang];
  pr  = new Intl.PluralRules(lang);
  nf0 = new Intl.NumberFormat(lang);
  nf1 = new Intl.NumberFormat(lang, { minimumFractionDigits: 1, maximumFractionDigits: 1 });
  document.documentElement.lang = lang;               // drives html[lang="de"] CSS + hyphens:auto
  if (persist) { try { localStorage.setItem(STORE, lang); } catch {} }
}

// {name} = literal param · {@name} = param VALUE is itself a key, resolved now
const RE = /\{(@?)(\w+)\}/g;
const fill = (s, p) => (p ? s.replace(RE, (m, at, k) => (k in p ? (at ? tr(p[k]) : p[k]) : m)) : s);

export function tr(key, params) {
  let v = table[key];
  if (v === undefined) v = EN[key];                    // EN is the fallback table, always
  if (v === undefined) {
    if (import.meta.env.DEV) console.warn('[i18n] missing key:', key, lang);
    return key;                                        // NEVER throw — see §G
  }
  if (Array.isArray(v)) v = v[(Math.random() * v.length) | 0];
  else if (typeof v === 'object') v = v[pr.select(params?.n ?? 1)] ?? v.other;
  return fill(v, params);
}

export const nf = (n, d = 0) => (d ? nf1 : nf0).format(n);

// Package defs carry ids only; display text resolves here.
export const pkgName = (d) => (d.golden ? tr('pkg.gold_name', { base: `pkg.${d.id}.name` }) : tr(`pkg.${d.id}.name`));
export const pkgNote = (d) => (d.golden ? tr('pkg.gold_note', { base: `pkg.${d.id}.note` }) : tr(`pkg.${d.id}.note`));
export const pkgWarn = (d) => (d.golden ? tr('pkg.gold_warn') : tr(`pkg.${d.id}.warn`));

// Dev/CI key-coverage audit (see §G)
export function trAudit() {
  const out = {};
  for (const L of LANGS) out[L] = Object.keys(EN).filter((k) => !(k in TABLES[L]));
  return out;
}
```

### Access pattern: module-level import, exported name `tr` — NOT `ctx.t`

**Justification against how this codebase actually works:**
1. The repo already crosses module boundaries with pure module-level helpers: `controller.js:2` imports `zoneAt`/`KILL_Y` from terrain, `packages.js:2` imports `disposeObject`. `tr` is exactly that shape — stateless, single-instance.
2. **`Hud` has no `ctx` at all.** `new Hud()` at main.js:121 takes zero arguments and the class never references ctx. `ctx.t` would force a constructor signature change on the single heaviest consumer of strings, purely for plumbing.
3. `ctx` is constructed at main.js:96 before any subsystem exists; there is exactly one game and one language — per-instance injection buys nothing.

**HARD REQUIREMENT — the export must be named `tr`, never `t`.** `t` is already bound as a parameter in `deliveries.js:191 fixedUpdate(dt, t)`, `director.js:51 fixedUpdate(dt, t)`, `packages.js:497 fixedUpdate(dt, t)`, and across `terrain.js` (`pathPoint(t)`, `gapAt(t)`, `update(dt, t)`). A top-level `import { t }` would be silently shadowed inside precisely the functions that need it — every call would pass a float as a key and render a number. Non-negotiable.

### Pluralization

`Intl.PluralRules` — native, zero dependency, correct for both languages including `n === 0` (EN `0 deliveries`, DE `0 Lieferungen` both select `other`). Only one plural key exists today (`hud.deliveries`); the machinery costs 3 lines and survives adding a third language.

```js
// strings.en.js
'hud.deliveries': { one: '{n} delivery',  other: '{n} deliveries' },
// strings.de.js
'hud.deliveries': { one: '{n} Lieferung', other: '{n} Lieferungen' },
```
Call site (hud.js:90): `this.deliveries.textContent = tr('hud.deliveries', { n });`

### Re-render on switch: **`hud.relabel()`, no listener registry**

There is no event bus and I am not adding one. Exactly one module owns every localizable DOM node: `Hud`. Therefore the switch is two statements:

```js
setLang(next);
hud.relabel();
```

**Why no pub/sub:** the only subscriber would ever be `Hud`. A `Set` of callbacks to serve one callee is ceremony. If the shift/results workstream adds screens, it extends `relabel()` — one function, one file, one place to look.

**What actually goes stale, and what self-heals.** Auditing the write paths:

- **Self-healing (rewritten every frame from `deliveries.update()` at main.js:219 → deliveries.js:221-238):** `#hud-target-label`, `#hud-target-dist`, `#hud-alt`, `#hud-timer`. These need *no* caching — one frame after the switch they are correct. Do not add state for them.
- **Stale, must be cached and re-rendered by `relabel()`:** the package name/note (written once at pickup, packages.js:487), `#hud-deliveries` and `#hud-chain` (written only on delivery, deliveries.js:178-179), the slip (written once at pickup, hud.js:137), `#hud-banner` (director.js:158/178 write once and it persists 2.5–9 s), all static markup in index.html, the title screen.
- **Deliberately NOT re-rendered: live toasts and score-pops.** A toast is a log entry of a moment; rewriting its text mid-fade reads as a rendering glitch. They all expire within 3.3 s (hud.js:133) / 2.6 s (hud.js:112). `toast()` keeps taking a resolved string; call sites do `hud.toast(tr('toast.delivered', { n: gained }))`.

## C) KEY NAMING SCHEME + FULL COPY TABLES

**Scheme:** flat, lowercase, dot-namespaced `area.thing[.variant]`, snake_case for multi-word leaves. Areas: `title` `ctrl` `hud` `slip` `pkg` `zone` `spot` `station` `event` `bonus` `pop` `chain` `toast` `quip` `shift` `results` `pause` `settings` `meta` `boot` `lang`. Params `{n}` `{name}` `{pct}` `{mult}` `{m}` `{base}` `{event}` `{reason}`; `{@x}` = nested key.

**Total ≈ 160 keys per language** (120 existing + ~40 new for shift/results/pause/settings).

### Proper nouns — DECISION: zone and spot names ARE localized; the company wordmark is NOT

These are not brands, they are *descriptive comedy place names*. "Sunny Meadows" is a joke about a blandly cheerful pastoral name; "The Summit Court" is a joke about a mountain having a bureaucracy. Leaving them English inside German copy reads as an untranslated asset — the German player sees the joke's shell but not the joke, and it makes the HUD look like a half-finished localization. Every German-language game and film localizes invented place names for exactly this reason (Auenland, Bruchtal).

**The line:** anything that would be printed on a *sign in the world* or is *descriptive* → localized (zones, spots, stations). Anything that is a *legal entity or logo asset* → identical in both languages (the fake-logistics wordmark from the branding workstream, so one SVG serves both). State this rule in the strings file header so nobody relitigates it per-string.

## D) GERMAN VOICE GUIDE

### Register: **Sie**, always, without exception

The game is corporate-logistics satire. German corporate, HR, insurance and postal language is emphatically *Siezen* — "Wir bitten um Verständnis", "Ihre Personalakte", "Bitte beachten Sie". The comedy engine of this game is **stiff institutional register colliding with absurd physics**, and in German that collision only fires with Sie. Duzen would flatten every line into generic-videogame tone and destroy the joke — a German player reading "Der Berg hat dich bemerkt" hears a mobile game; "Der Berg hat Sie zur Kenntnis genommen" hears an authority filing a report about them.

Exception: shouty impersonal HUD words (`STEINSCHLAG!`, `ZUGESTELLT!`, `LAWINE`) have no addressee and stay imperative/nominal. Infinitive-imperative ("Warm halten.", "Nicht schütteln.") is correct for instruction-sheet copy on the slip — that is how German product labels are actually written, and it is *more* formal than Sie, not less.

### Landing the deadpan without sounding machine-translated

1. **Translate the bureaucratic *move*, not the sentence.** "Noted in your performance review" → the German bureaucratic artifact with the same emotional weight is the **Personalakte**, not a calqued *Leistungsbeurteilung* in that sentence. Find the German institution that does the same job.
2. **Prefer officialese verbs**: `wurde vermerkt`, `gilt als`, `entfällt`, `wird angepasst`, `zur Kenntnis genommen`, `anberaumt`, `erfolgt dennoch`, `sich begeben`, `ist zu unterlassen`. These are flat in English and hilarious in German because nobody speaks that way outside an Amt.
3. **Passive + nominalization is a comedy asset in German** where it is limp in English. `Paketverlust wurde erfasst.` beats `Sie haben ein Paket verloren.`
4. **Never calque an English idiom.** "On a roll" is not *auf einer Rolle*; it is **LÄUFT**. "Close one" is not *naher Anruf*; it is **KNAPP**.
5. **Punctuation is register.** German officialese loves the terse colon (`Inhalt: unauffällig.`) and the full stop where English uses an exclamation mark. Replacing `!` with `.` is often the entire joke: `Bitte zum Depot-Schacht begeben.`
6. **Trim, don't pad.** Bad DE localization is 40% longer because it explains. Good DE localization is often *shorter* than the English because one compound noun replaces a phrase (`ZUM SCHICHTBEGINN KLICKEN` < `CLICK TO START YOUR SHIFT`).
7. **Typographic conventions**: `3,0` not `3.0`; `1.240` not `1,240`; a space before `%` and before units (`42 m`, `5 s`, `74 %`). These are free credibility and their absence instantly reads as a translated-from-English asset.

### Compound nouns that are funnier in German — exploit these

Already deployed above: **Wiederbeschaffungskosten** (replacement procurement costs, for "comes out of your pay"), **Gefahrenzulage** (hazard pay), **Leistungsbeurteilung**, **Personalakte**, **Betriebsunfall**, **Aktenvermerk**, **Versicherungsfall**, **Selbstbeteiligung** (deductible), **Wiedereinsetzungsgebühr**, **Arbeitsschutzverordnung**, **Schichtbeginn**, **Schichtbericht**, **Nettoauszahlung**, **Betriebsfunk**, **Bauchrutsche**, **Sturmgipfel**, **Geisterpaket**, **Eisfischerlager**.

Held in reserve for new copy: **Abmahnung** (formal written warning — the German HR nuclear option, *no English equivalent*), **Betriebsrat** (works council), **Eigenkündigung**, **Zustellnachweis**, **Empfängerabwesenheit**, **Beförderungsbedingungen**, **Schwerlastzuschlag**, **Sonderzustellungszuschlag**, **Sachbeschädigung**, **Bergungskosten**, **Kostenstelle**, **Arbeitszeiterfassung**, **Nachweispflicht**, **Restwert**.

The rule: a compound is funny when it is *bureaucratically over-precise about something absurd*. `Wiederbeschaffungskosten` for a crate of angry sheep is funnier than any English phrasing available.

### German-only jokes worth adding where the English has none

1. **Abmahnung escalation on repeated falls.** German labour law has a real three-stage escalation: *Aktenvermerk* (note in file) → *Ermahnung* (informal reprimand) → *Abmahnung* (formal written warning, legal precondition for dismissal). Wire the respawn counter to escalate through them; the fourth fall yields `📄 Bei der nächsten Abmahnung sprechen wir über Ihre Zukunft im Unternehmen.` This is untranslatable and lands like a hammer for German players. **New key: `quip.respawn_escalation` array, DE-only, EN falls through to `quip.respawn`.**
2. **TÜV on the anvil.** `pkg.anvil.note` DE alternate: `TÜV-geprüft. Der Prüfer ist nicht zurückgekehrt.` TÜV is the German technical inspection authority; "the inspector did not come back" is peak deadpan.
3. **DWD storm warning levels.** German weather warnings are colour-graded and nationally famous. `event.incoming` DE variant for thunder: `⚠ AMTLICHE UNWETTERWARNUNG DER STUFE ROT` ("official severe weather warning, level red"). *Amtlich* = officially issued. **New key: `event.incoming_official`.**
4. **Ghost package form language.** Already deployed: `Empfänger verstorben. Zustellung erfolgt dennoch.` — verbatim Deutsche-Post delivery-attempt phrasing.
5. **Sheep invokes the works council.** Alternate `toast.sheep_loose` DE: `🐑 DAS SCHAF HAT DEN BETRIEBSRAT EINGESCHALTET!` Livestock filing a labour complaint has no English equivalent of comparable weight.
6. **Bonus expiry as legal deadline.** Deployed: `Frist verstrichen.` A German player reads a missed *Frist* as legally consequential.
7. **Vollkasko ohne Selbstbeteiligung** for golden cargo — the German car-insurance gold standard, instantly recognizable.
8. **Betriebsfunk** for the music toggle (deployed).

## E) LAYOUT CONSEQUENCES

German runs 20–35% longer. Use **`html[lang="de"]` CSS overrides** for per-language tweaks — `setLang()` already writes `document.documentElement.lang`, so this needs zero extra JS.

### E1 — `#hud-hint` (index.html:125–128) — **WILL BREAK**
`white-space: nowrap` + `left:50%; transform:translateX(-50%)`. The EN string is ~150 chars at 12.5 px ≈ 1050 px. The DE equivalent is ~1350 px: it overflows a 1280 px viewport and, because it is nowrap and centered by transform, it bleeds off **both** edges with no scroll and no clip.

**Fix** — drop nowrap, wrap as flex pills (also removes the markup-embedded strings):
```css
#hud-hint {
  position:absolute; bottom:14px; left:50%; transform:translateX(-50%);
  padding:6px 16px; font-size:12.5px; color:#bcd3f5;
  max-width:min(94vw, 1180px);
  display:flex; flex-wrap:wrap; justify-content:center; align-items:center;
  gap:2px 14px; line-height:1.5; text-align:center;
}
#hud-hint kbd { color:#ffd166; font:inherit; font-weight:700; }
html[lang="de"] #hud-hint { font-size:11.5px; gap:2px 11px; }
```

### E2 — `#hud-target-label` (index.html:110) + `#hud-target` (index.html:104–107)
`letter-spacing:1.5px` adds ~1.5 px/char. `ZUSTELLEN AN · EISFISCHERLAGER` is 30 chars ≈ 260 px at 10 px + tracking. The panel is `translateX(-50%)` centered and must not collide with `#hud-top-left` (min-width 230 px + 14 px) or `#hud-top-right`.

**Fix**:
```css
#hud-target { max-width:min(46vw, 520px); }
#hud-target-label { letter-spacing:1.5px; overflow-wrap:anywhere; }
html[lang="de"] #hud-target-label { letter-spacing:1.1px; font-size:9.5px; }
```
Label wrapping to two lines is acceptable — the panel grows downward and nothing sits under it.

### E3 — `#hud-banner` (index.html:112–120) — **CENTERING TRAP**
24 px / weight 900 / `letter-spacing:1px`, `padding:8px 30px`. The worst DE case is `🪨 STEINSCHLAG! · ☂ GEFAHRENZULAGE +142` ≈ 38 chars ≈ 660 px — fine at 1280, clipped at 1024.

**Fix**:
```css
#hud-banner { font-size:clamp(15px, 2.05vw, 24px); max-width:92vw; white-space:nowrap; }
html[lang="de"] #hud-banner { letter-spacing:.4px; padding:8px 22px; }
```
**Hard warning:** the `banner-pulse` keyframes at index.html:120 re-declare `transform: translateX(-50%) scale(…)`. Any fix that changes how the banner is centered must update the base rule at index.html:113 **and both keyframe steps**, or the banner snaps sideways every 0.35 s. Do not switch to `margin:auto` / `inset-inline` without rewriting the keyframes.

### E4 — `#slip` (index.html:152–168) — **CSS `content` IS A HARD BLOCKER**
Two separate problems.

**(a) The header at index.html:162 is CSS-generated and cannot be reached from JS.** `content:'DELIVERY SLIP #' attr(data-num)` is static text baked into the stylesheet.
**Fix — required:**
```css
#slip::before { content: attr(data-title) ' #' attr(data-num); }
```
and in `relabel()`: `this.slip.dataset.title = tr('slip.header');`. index.html:214 gains `data-title="DELIVERY SLIP"` as the pre-boot default.

**(b) Fixed `width:250px` + `'Courier New'` monospace at 13 px** ≈ 7.8 px/char → ~28 usable chars/line. German compounds are unbreakable: `Wiederbeschaffungskosten` = 24 chars = 187 px (fits, barely), `Sonderzustellungszuschlag` = 25. Anything ≥ 29 chars overflows, and Courier will not break mid-word.

## F) LANGUAGE SWITCH UX

### Where it lives: title screen **and** pause/settings panel — one shared builder

```js
// hud.js
mountLangSwitch(host) {
  const wrap = document.createElement('div');
  wrap.className = 'lang-switch';
  wrap.setAttribute('role', 'group');
  wrap.setAttribute('aria-label', tr('lang.aria'));
  for (const L of LANGS) {
    const b = document.createElement('button');
    b.type = 'button'; b.dataset.lang = L; b.textContent = L.toUpperCase();
    b.setAttribute('aria-pressed', String(L === getLang()));
    b.addEventListener('click', () => {
      if (L === getLang()) return;
      setLang(L);
      this.relabel();
      for (const s of host.querySelectorAll('.lang-switch button'))
        s.setAttribute('aria-pressed', String(s.dataset.lang === L));
    });
    wrap.appendChild(b);
  }
  host.appendChild(wrap);
  return wrap;
}
```
Called twice: `hud.mountLangSwitch(document.getElementById('title-screen'))` in `boot()` (main.js, after line 145) and `hud.mountLangSwitch(pausePanelEl)` by the shift workstream.

### **CRITICAL GOTCHA #1 — the title-screen click handler will eat the language click**
main.js:146 binds `startGame` to the **entire** `#title-screen` with `{ once: true }`. A click on the EN/DE button bubbles up and starts the game — and because of `{ once: true }` the listener is already consumed, so there is no recovery. This is the single most likely implementation bug.

**Fix at main.js:146 — replace `{ once: true }` with a guarded self-removing handler:**
```js
const ts = document.getElementById('title-screen');
const onTitleClick = (e) => {
  if (e.target.closest('#lang-switch')) return;   // language buttons are not "start"
  ts.removeEventListener('click', onTitleClick);
  startGame();
};
ts.addEventListener('click', onTitleClick);
```
This is preferable to `stopPropagation()` on the button because it keeps the "click anywhere to start" affordance intact while carving out exactly one region.

### **CRITICAL GOTCHA #2 — `#hud` is `pointer-events:none`**
index.html:46. Any switch mounted inside `#hud` (including the pause panel if it lives there) needs `pointer-events:auto` on itself — already in the CSS above, but the pause panel container needs it too.

### Availability mid-shift: **yes, but only from pause**
Not from the live HUD. Rationale: the switch triggers a full `relabel()` which repaints the package panel, banner and slip — doing that mid-flight while a boulder is inbound is a visual hiccup at the worst moment. Pause already halts the simulation, so nothing is lost. Switching is fully non-destructive: score, chain, completed count, physics state are untouched; only `textContent` changes. Live toasts on screen at the moment of switch are deliberately left alone (they expire ≤3.3 s).

No keyboard shortcut. `M` is already taken (main.js:166) and a hotkey nobody asked for is one more thing to collide with the pause key the shift workstream is adding.

### Default detection & precedence
`?lang=` query param → `localStorage['ud.lang']` → `navigator.languages[0]`/`navigator.language` first two chars → `'en'`. Query first so the test harness and shared links are deterministic regardless of the machine's locale. Persisted on every user-initiated `setLang`, never on `initLang`.

`localStorage` access is wrapped in try/catch — a `SecurityError` in a sandboxed iframe or with third-party cookies blocked must not take the boot path down (verify.mjs fails on any console error, see §G).

### Boot order — **must run before the first paint**
`initLang()` is called at **module scope in main.js, immediately after the imports (before line 16)** — not inside `boot()`. index.html's static markup is already in the DOM when the module evaluates, and `boot()` is async (it awaits `physics.init()` and `character.load()`), so deferring would show English markup to a German player for the entire load. The `Hud` constructor's trailing `this.relabel()` (main.js:121) then stamps everything.

### THE ONE HARD REQUIREMENT: `tr()` must never throw and must never `console.warn` in a production build

verify.mjs:18–21 fails the whole run on **any** `console.error`, `pageerror`, `requestfailed`, or HTTP ≥400, and exits 2 at :395. Therefore:
1. `tr()` returns the key string on a miss — never throws, never returns `undefined`.
2. The miss warning is gated behind `import.meta.env.DEV`, which Vite statically replaces with `false` in `vite build`. verify.mjs runs against `vite preview` (`http://localhost:4173/`), i.e. the built bundle → the warn branch is dead-code-eliminated. **If anyone removes that gate, CI turns red on the first missing DE key.**
3. `localStorage` reads/writes are try/catch-wrapped (a `SecurityError` would be an uncaught `pageerror`).
4. The two new string modules are static ESM imports bundled by Vite — no `fetch`, no dynamic `import()`, no JSON file. A network-loaded locale would trip the `requestfailed` and HTTP≥400 listeners on any path/base mistake (`vite.config.js` uses `base:'./'`, which makes runtime-constructed asset URLs fragile). **Do not lazy-load locales.**

### Language the harness should force: **`en`, explicitly, via the query param**

Change verify.mjs:23:

await page.goto(URL + (URL.includes('?') ? '&' : '?') + 'lang=en');

Headless Chromium reports `navigator.language === 'en-US'` so EN would be picked anyway, but pinning removes a hidden dependency on the CI runner's locale (`LANG`/`--lang` flags do change `navigator.language`) and on any `localStorage` left over inside a reused browser context.
